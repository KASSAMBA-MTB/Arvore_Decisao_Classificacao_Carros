# Métodos de Classificação Supervisionada

Repositório da disciplina **COM360 – Mineração de Dados**, com foco em **classificação supervisionada**, apresentando exemplos práticos de criação e avaliação de **árvores de decisão** utilizando a biblioteca `scikit-learn`.

---

## 📌 Objetivo

Demonstrar, de forma prática, a aplicação de técnicas de aprendizado supervisionado, com ênfase em modelos de **árvore de decisão**, desde a preparação dos dados até a avaliação dos resultados.

---

## 🧠 Conteúdos abordados

- Conceitos de classificação supervisionada  
- Preparação e tratamento de dados  
- Treinamento de modelos com `scikit-learn`  
- Construção de árvores de decisão  
- Avaliação de desempenho (acurácia, matriz de confusão, etc.)  

---

## 🛠️ Tecnologias utilizadas

- Python  
- scikit-learn  
- pandas  
- matplotlib
